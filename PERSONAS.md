# Flow — Personas

## Persona 1 — The Overloaded Planner

### Description

A professional who has many responsibilities and frequently has more tasks than available time.

### Goals

- Know what to do next.
- Avoid forgetting tasks.
- Understand whether the day is realistic.
- Quickly reschedule when plans change.
- Reduce time spent organizing tasks.

### Problems

- Creates large todo lists.
- Underestimates task duration.
- Frequently moves unfinished tasks.
- Has difficulty deciding priorities.
- Uses multiple tools to manage commitments.

### Flow Value

Flow should help this user transform a large collection of tasks into a realistic plan.

## Persona 2 — The Self-Directed Learner

### Description

A person working toward a long-term personal goal while balancing work and everyday responsibilities.

Examples:

- learning a language;
- learning programming;
- preparing for an exam;
- building a side project.

### Goals

- Make consistent progress.
- Break large goals into smaller tasks.
- Find time for learning.
- Maintain progress without excessive planning.

### Problems

- Large goals feel vague.
- Learning tasks are easily postponed.
- Daily work competes with long-term goals.

### Flow Value

Flow should help turn long-term intentions into manageable actions while protecting realistic time for them.
