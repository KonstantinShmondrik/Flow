# Flow

AI-assisted personal planner for iOS.

Flow helps users turn tasks, intentions, and constraints into a realistic daily plan — and adapt that plan when reality changes.

## Project Status

🚧 Early development — Phase 0: Product & Engineering Foundation

## Vision

Flow is designed to become an adaptive personal planning assistant rather than a traditional todo list.

The user remains in control:
AI proposes, the application validates, and the user decides.

## Technology

The project is built as an experiment with modern Apple technologies:

- Swift 6
- SwiftUI
- Observation
- Swift Concurrency
- SwiftData
- Foundation Models
- App Intents
- WidgetKit
- ActivityKit
- CloudKit
- Swift Testing
- Xcode Cloud

Technologies will be introduced incrementally as the product evolves.

## AI-Driven Development

Flow is also an experiment in AI-agent-driven software development.

AI agents participate in:

- product analysis;
- architecture;
- implementation;
- testing;
- code review;
- documentation;
- release preparation.

Human decisions remain the final authority for product, architecture, and release.
