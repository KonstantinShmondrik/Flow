# Flow — Product Vision

## Vision

Flow should become a personal planning layer between what a person wants to accomplish and the limited time and attention they actually have.

Instead of asking the user to manually construct a perfect schedule, Flow should help them continuously adapt their plan to reality.

---

## The Core Idea

Plans are not static.

A user may:

- start the day late;
- receive an unexpected meeting;
- spend longer on a task;
- cancel an activity;
- suddenly have free time;
- add an urgent task.

A useful planner should adapt.

Flow therefore treats planning as a continuous process rather than a one-time scheduling operation.

---

## AI Philosophy

AI should reduce cognitive overhead, not replace user agency.

Flow should behave more like:

> "Here is what I think you should do. Would you like me to apply it?"

and less like:

> "I changed your schedule."

---

## Long-Term Experience

The ideal Flow experience is:

### Capture

The user can quickly express an intention naturally.

### Understand

Flow converts the intention into structured information.

### Plan

Flow considers time, priorities, constraints and preferences.

### Execute

The user follows the plan.

### Adapt

Flow helps when reality diverges from the plan.

### Reflect

Flow helps the user understand patterns over time.

---

## Product Personality

Flow should feel:

- calm;
- intelligent;
- predictable;
- lightweight;
- respectful;
- transparent.

It should not feel:

- overwhelming;
- gamified;
- judgmental;
- intrusive;
- obsessed with productivity.

---

## Long-Term Direction

Flow should evolve from a simple task manager into an adaptive personal planning assistant.

The product should gradually move through several stages:

**Task management**  
Help users capture, organize, and complete what needs to be done.

→

**Planning assistance**  
Help users turn their tasks, priorities, and available time into realistic plans.

→

**Adaptive planning**  
Continuously adjust plans when circumstances change, while keeping the user in control of important decisions.

→

**Personalized planning**  
Use relevant information about the user's preferences, routines, commitments, and past planning behavior to make recommendations increasingly useful and realistic.

The long-term goal is not to automate the user's life, but to build a system that understands enough of the user's planning context to provide meaningful assistance.

The user remains in control of their data, plans, and decisions. Personal context should be transparent, limited to what is useful for planning, and manageable by the user.
